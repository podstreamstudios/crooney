## Key concepts

- **P·S·L** — Products (songs) · Services (sets/performance) · Licences (venues/events)
- **S/E/E/D** — Study → Explore → Evaluate → Design (Flynn 2010)
- **RPV** — Resources · Processes · Values (Christensen et al.)
- **F|D|S|L|** — Food · Drink · Sound · Light (experience design registers)
- **The tacklebox doesn't control the river** — F|D|S|L| as interpretive instruments, not a control mechanism
